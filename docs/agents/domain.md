# Domain Docs

工程技能探索代码库前，应读取与当前工作相关的领域文档。

## 读取规则

- 读取项目根目录的 `CONTEXT.md`
- 如果存在 `CONTEXT-MAP.md`，读取其中指向的相关上下文文档
- 读取 `docs/adr/` 中与当前工作相关的架构决策
- 文件不存在时静默继续，不提前创建空文档
- `/grill-with-docs` 或 `/domain-modeling` 在真正形成术语或决策时再创建内容

## 当前布局

本项目采用单上下文布局：

    /
    ├── CONTEXT.md
    ├── docs/adr/
    └── src/

## 术语规则

输出中的领域概念应使用 `CONTEXT.md` 已定义的术语，不随意改用近义词。需要的新概念应通过领域建模确认。

## ADR 冲突

如果方案与现有 ADR 冲突，必须明确指出，不得静默覆盖已有决策。
