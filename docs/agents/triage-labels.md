# Triage Labels

| 技能中的角色 | 本项目状态值 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交给 Agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或处理 |
| `wontfix` | `wontfix` | 不计划处理 |

技能提及某个 Triage 角色时，使用本表对应的状态值。
