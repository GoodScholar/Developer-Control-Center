# 06: 按依赖关系运行多服务项目

**What to build:** Start All 根据无环服务依赖图启动整个开发项目，独立分支并行运行，失败传播为阻塞；Stop All 按反向依赖优雅停止，重复启动保持幂等。

**Blocked by:** 05/启动单个开发服务并实时查看日志

**Status:** ready-for-agent

- [ ] 项目配置可以声明服务依赖，并在保存或启动前拒绝依赖循环和不存在的依赖。
- [ ] Start All 只在依赖达到可用状态后启动下游服务。
- [ ] 没有相互依赖的服务分支可以并行启动。
- [ ] 一个分支失败时，依赖它的服务进入 Blocked，独立分支继续运行。
- [ ] 未配置健康检查的稳定运行服务以 Running 作为可用状态。
- [ ] 重复执行 Start All 时跳过 Starting 或 Running 的服务，只处理尚未运行的目标服务。
- [ ] Stop All 按反向依赖顺序停止全部受管进程，并保持单服务停止契约。
- [ ] 依赖、并行、部分失败、阻塞传播、幂等与反向停止均通过 Control Center 接口测试。
