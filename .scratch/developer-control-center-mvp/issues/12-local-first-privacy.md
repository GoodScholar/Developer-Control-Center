# 12: 落实本地优先隐私与数据控制

**What to build:** 应用将文件和网络访问限制在已确认范围内，不要求管理员权限、不泄露环境值；用户可以主动导出脱敏诊断包，并清除历史而保留项目注册和仓库配置。

**Blocked by:** 02/手动创建可移植的单服务项目配置, 10/完成单服务与合并日志体验

**Status:** ready-for-agent

- [ ] 应用只访问用户注册的开发项目、明确选择的 `.env` 文件和应用自身数据目录。
- [ ] 项目配置中的相对路径无法越出开发项目根目录，包括符号链接解析后的结果。
- [ ] 应用核心功能不需要管理员或 root 权限，也不尝试自动提权。
- [ ] 默认无账户、无云后端、无遥测或自动崩溃上传。
- [ ] 网络访问只来自用户配置的健康检查和 GitHub Release 版本检查。
- [ ] 用户主动导出的诊断包移除环境变量值和产品能够识别的密钥内容。
- [ ] 清除历史数据删除运行摘要、日志和界面状态，但保留项目注册及仓库项目配置。
- [ ] 密钥脱敏、路径限制、网络范围和数据清除均有安全回归测试。
