# 01: 建立可持久化的项目注册闭环

**What to build:** 用户可以启动桌面应用、选择本地目录、注册开发项目、重启应用后继续看到项目，并安全取消注册。该纵向切片同时建立 Control Center 主测试缝、Host Runtime 测试适配器和双平台持续集成骨架。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 应用可在 macOS 13+ 和 Windows 11 的开发环境中启动，并显示空项目列表。
- [ ] 用户选择本地目录后，该目录作为开发项目出现在项目列表中。
- [ ] 关闭并重新打开应用后，已注册开发项目仍然存在。
- [ ] 用户取消项目注册后，只删除本地注册记录，不修改或删除开发项目中的任何文件。
- [ ] 项目目录不可访问或已被移动时，界面显示发生了什么以及用户可以采取的下一步。
- [ ] 项目注册行为通过 Control Center 模块接口测试，不依赖持久化实现细节。
- [ ] 自动化测试使用 Host Runtime 测试适配器，并在 macOS 与 Windows CI 中运行。
