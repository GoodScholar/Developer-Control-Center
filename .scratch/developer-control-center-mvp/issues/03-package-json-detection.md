# 03: 从 package.json 生成检测建议

**What to build:** 用户添加 Node 项目后可以看到由 `package.json` 推断出的检测建议，并能编辑、拒绝或确认写入项目配置；检测本身绝不执行命令。

**Blocked by:** 02/手动创建可移植的单服务项目配置

**Status:** ready-for-agent

- [ ] 注册包含 `package.json` 的开发项目时，应用生成候选长期运行服务的检测建议。
- [ ] 检测建议清楚展示程序、参数、工作目录和推断来源。
- [ ] 用户可以在确认前编辑建议，并通过与手动配置相同的校验规则。
- [ ] 用户拒绝建议时，不创建项目配置，也不执行任何候选命令。
- [ ] 用户确认建议后，应用生成有效且可版本控制的项目配置。
- [ ] 检测过程不运行 package scripts，不读取项目根目录之外的文件。
- [ ] 示例 Node 项目的检测、拒绝、编辑和确认路径均有外部行为测试。
