# 05: 启动单个开发服务并实时查看日志

**What to build:** 用户可以启动和停止一个开发服务，看到准确状态、ANSI 运行日志和可操作启动错误；停止后不遗留由应用启动的子进程。

**Blocked by:** 02/手动创建可移植的单服务项目配置

**Status:** ready-for-agent

- [ ] 启动前检查配置的程序是否可用，缺失时提供修复方向且不自动安装。
- [ ] 结构化程序与参数在 macOS 和 Windows 具有一致的用户可见语义。
- [ ] 显式 Shell 模式可以启动用户确认的 Shell 命令，默认模式不经过 Shell 字符串拼接。
- [ ] 服务状态按 Stopped、Starting、Running、Stopping、Stopped 转换，异常退出时进入 Failed。
- [ ] 标准输出和标准错误实时显示，并保留 ANSI 表现信息与来源服务。
- [ ] 启动错误包含受影响服务、失败原因和用户可采取的下一步。
- [ ] 停止先请求优雅退出，默认等待 10 秒，超时后终止完整受管进程树。
- [ ] macOS、Windows 与测试 Host Runtime 适配器通过同一进程生命周期契约测试。
