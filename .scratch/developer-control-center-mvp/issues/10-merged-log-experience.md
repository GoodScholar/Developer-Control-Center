# 10: 完成单服务与合并日志体验

**What to build:** 用户可以在单服务和 All Services 日志之间切换，搜索、筛选和复制记录；运行摘要可恢复，日志按七天或 500 MB 全局上限自动清理。

**Blocked by:** 05/启动单个开发服务并实时查看日志

**Status:** ready-for-agent

- [ ] 项目详情提供单服务日志与 All Services 合并日志视图。
- [ ] 合并日志按采集时间排列，每条记录保留来源服务及 stdout/stderr 来源。
- [ ] 用户可以按服务筛选、搜索文本并复制选中日志。
- [ ] 日志面板保持只读，不提供终端输入或 PTY 交互。
- [ ] 运行摘要保存到本地元数据存储，持续日志保存在独立限额文件中。
- [ ] 超过七天或全局 500 MB 时优先清理最旧日志，任一限制先达到即执行。
- [ ] 大量日志持续进入时，界面不会因无界列表或同步持久化明显卡顿。
- [ ] 合并顺序、来源标记、搜索筛选、保留期和容量清理均有外部行为测试。
