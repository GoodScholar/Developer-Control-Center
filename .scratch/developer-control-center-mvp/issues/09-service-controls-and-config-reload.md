# 09: 提供局部服务控制和配置热重载

**What to build:** 用户可以单独启动、停止或重启开发服务；外部项目配置变化会重新校验，运行中变更只提示重启，不静默替换进程或自动级联。

**Blocked by:** 06/按依赖关系运行多服务项目

**Status:** ready-for-agent

- [ ] 用户可以单独启动依赖已满足的开发服务。
- [ ] 用户可以单独停止或重启开发服务，并看到可能受影响的下游服务。
- [ ] 重启上游服务不自动重启下游，是否继续由用户明确决定。
- [ ] 外部修改项目配置后，应用自动重新读取并执行完整校验。
- [ ] 无效外部配置不替换最后一份有效运行定义，并显示可操作错误。
- [ ] 修改运行中服务的配置后，应用提示重启，但不静默停止或替换当前进程。
- [ ] 配置删除、模式不兼容和项目目录不可访问均进入明确、可恢复的用户流程。
- [ ] 单服务控制和配置重载通过 Control Center 接口验证，不依赖文件监听实现细节。
