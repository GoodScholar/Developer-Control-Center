# 13: 完成双平台 MVP 验收与质量加固

**What to build:** macOS 13+ 和 Windows 11 通过同一 Host Runtime 契约与真实桌面关键路径，并达到键盘访问、系统主题、目标规模和资源预算，形成可发布候选版本。

**Blocked by:** 03/从 package.json 生成检测建议, 04/从 Docker Compose 生成检测建议, 06/按依赖关系运行多服务项目, 07/用健康检查形成可信项目状态, 08/安全处理预期端口和外部冲突, 09/提供局部服务控制和配置热重载, 10/完成单服务与合并日志体验, 11/实现可信的桌面驻留生命周期, 12/落实本地优先隐私与数据控制

**Status:** ready-for-agent

- [ ] macOS 13+ 和 Windows 11 的 Host Runtime 适配器通过同一启动、停止、状态、端口和错误契约测试。
- [ ] 两个平台的真实桌面测试均完成添加示例项目、审核检测建议、生成配置、Start All、查看状态与日志、Stop All。
- [ ] 真实桌面测试确认 Stop All 后不遗留应用启动的子进程。
- [ ] 界面跟随系统明暗主题，核心导航和操作支持键盘并具有清晰焦点状态。
- [ ] 应用验证最多注册 50 个项目、同时运行 5 个项目、每个项目 10 个开发服务的目标规模。
- [ ] 无项目运行时平均 CPU 低于 1%，应用空闲内存目标低于 200 MB。
- [ ] 管理 10 个持续输出日志的服务时界面无明显卡顿，日志可见延迟目标低于 500 毫秒。
- [ ] 所有配置、进程、安全、日志和桌面验收测试在 macOS 与 Windows CI 上通过。
