# 08: 安全处理预期端口和外部冲突

**What to build:** 用户可以为服务声明预期端口，在启动前识别外部占用者并获得安全处理信息；HTTP 服务可以从应用打开系统浏览器。

**Blocked by:** 05/启动单个开发服务并实时查看日志

**Status:** ready-for-agent

- [ ] 预期端口为可选配置，不监听端口的服务仍可正常运行。
- [ ] 启动前发现端口被占用时，应用停止该服务的启动并展示端口、PID 与进程名。
- [ ] 冲突界面提供可复制的人工处理命令，但不自动执行该命令。
- [ ] 应用不自动终止、接管或向外部进程发送信号，也不请求管理员权限。
- [ ] 端口释放后，用户可以安全重试服务启动。
- [ ] 配置 HTTP 健康检查或可用 HTTP 入口的服务显示 Open in Browser，并交给系统默认浏览器。
- [ ] 外部进程安全边界与浏览器入口在 macOS、Windows 契约测试中语义一致。
