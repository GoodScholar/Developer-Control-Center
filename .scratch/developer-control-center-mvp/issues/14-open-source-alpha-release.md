# 14: 发布可验证的开源 Alpha

**What to build:** GitHub Releases 提供 Apache-2.0 源码、macOS 与 Windows 安装包及校验和；应用可以提示新版本但不自动安装，未签名 Alpha 清楚说明安装和信任边界。

**Blocked by:** 13/完成双平台 MVP 验收与质量加固

**Status:** ready-for-agent

- [ ] 仓库包含完整 Apache-2.0 许可证和面向贡献者的构建、测试与安全边界说明。
- [ ] 发布流程从已验证版本生成 macOS 与 Windows 安装包及对应校验和。
- [ ] GitHub Release 同时包含源码、安装包、校验和、已知限制和升级说明。
- [ ] 未签名 Alpha 明确解释操作系统警告和安全安装步骤，不暗示安装包已签名或公证。
- [ ] 应用可以检查新的 GitHub Release 并提示用户前往发布页面，但不自动下载或安装。
- [ ] 版本检查失败不影响项目注册、启动、停止、健康检查或日志等本地核心能力。
- [ ] 应用不会随系统登录启动，也不会在启动应用时自动运行任何开发项目。
- [ ] 发布前再次运行 macOS 与 Windows 的完整验收和安装包冒烟测试。
