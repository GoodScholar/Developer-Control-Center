# 11: 实现可信的桌面驻留生命周期

**What to build:** 关闭窗口后应用继续在系统托盘管理项目；异常事件触发低噪声通知；显式退出会处理运行中服务；异常重启后遗留进程进入待处理状态而不会被自动接管。

**Blocked by:** 07/用健康检查形成可信项目状态, 08/安全处理预期端口和外部冲突, 10/完成单服务与合并日志体验

**Status:** ready-for-agent

- [ ] 应用只允许一个实例管理所有项目、本地元数据和受管进程。
- [ ] 关闭主窗口时应用驻留系统托盘，正在运行的开发服务继续受到管理。
- [ ] 托盘可以重新打开主窗口并反映最新项目状态。
- [ ] 服务失败、健康恶化和需要处理的端口冲突触发系统通知，正常启动和停止不通知。
- [ ] 显式退出时，应用提示处理运行中的项目并可执行 Stop All。
- [ ] 应用异常退出后重启，不依据旧 PID 自动接管或终止仍存活的进程。
- [ ] 发现疑似遗留进程时，项目进入 Needs Attention 并提供安全处理说明。
- [ ] 单实例、托盘、退出和异常恢复行为在 macOS 与 Windows 上均有验证。
